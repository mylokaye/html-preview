# VS Preview

VS Preview opens the active HTML file in a browser-like panel beside the editor. It supports regular folders and virtual workspaces, including repositories opened with the GitHub Repositories extension.

## Use

1. Open an `.html` or `.htm` file.
2. Run **Preview HTML** from the Command Palette, or click **Preview HTML** in the editor title/context menu.

Edits to the open HTML document appear in the preview as you type. Relative images, stylesheets, and scripts resolve from the file's folder. The preview runs in a sandboxed webview and limits workspace file access to that folder.

## Run the extension

Open this folder in VS Code and press **F5** to launch an Extension Development Host. In that window, open an HTML file and run **Preview HTML**.
